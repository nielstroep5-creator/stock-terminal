# Security

Stock Terminal runs on your own computer and keeps your data there. It talks to the SEC, Yahoo Finance, GitHub
(updates and the starter pack), ntfy (only when you turn on phone alerts) and Trading 212 (only with your own
read-only key).

If you find a security problem, please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/nielstroep5-creator/stock-terminal/security/advisories/new).
We will answer as soon as we can.

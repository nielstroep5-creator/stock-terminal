# Who is working on what

Write a line here (and push it) before you start something bigger than a small fix, and remove it when
it is done. Then two people (or two Claudes) never change the same part at the same time.

Format: `- name: what you are doing (files or part of the app) - since date`

Example:
- Niels: Compare page, saved charts (app.js compare section) - since 2026-11-15
